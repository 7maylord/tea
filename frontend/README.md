# TEA frontend

Install and run this app from `frontend/`:

```sh
pnpm install
pnpm dev
```

The app runs at <http://127.0.0.1:3000>. Build with `pnpm build` and check lint with `pnpm lint`. Backend dependencies are installed separately in `backend/`.

This is the initial Next.js shell. Payment screens and wallet integration are still being implemented; do not treat the starter page as a working payment flow.
